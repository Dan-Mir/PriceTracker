# Test Scripts

Questa cartella contiene script di test e debug.

## Script di Test Principali

### tests/
- `test_integration.py` - Test di integrazione completi
- `test_parser_utils.py` - Test utility parser
- `test_db.py` - Test database
- `run_tests.py` - Esegue tutti i test

## Script di Debug

### tests/debug_scripts/
Script usati durante lo sviluppo per esplorare e debuggare:

- `debug_castoro.py` - Debug generale Castoro
- `explore_castoro.py` - Esplorazione struttura sito
- `explore_menu_castoro.py` - Test apertura menu
- `extract_subcategories.py` - Estrazione sottocategorie
- `force_menu_open.py` - Test apertura forzata menu

Questi script sono stati utilizzati durante lo sviluppo del parser Castoro
e sono mantenuti per riferimento futuro.
